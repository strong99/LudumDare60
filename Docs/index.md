# Boilerkeep

Boilerkeep is a small Ludum Dare 60 game built in 48 hours. In this game you defend the tower core from enemy goblins that try and infiltrate. To defend you have an inventory of traps available, sadly these require pipes, and pipes can break.

The player needs to defend the tower core until it completes: core activation, which releases an android into the world in the outro.

Traps operate on pressure. Pressure is generated by boilers. 

## Definition
### World
The world is a tiled space. A tile can be solid or open. An open tile can be walked on and contraptions can be placed on those. Pipes can be placed on the tile's edges.

### Construction
Constructing and repairing machinery, pipes and walls cost scrap. Scrap is  gained for each wave. Killing enemies also gifts scrap.

There are two construction grids: 
- tile (traps, boilers)
- tile edge (pipes, walls)

Walls block paths, this translates to enemies as avoidance. If the path supersedes avoidance they will be attacked

### Traps
- Crusher: a plate that crushes enemies, take one tile
- Nails: come from the ground, take one tile
- Saws: come from the ground and walls, take one tile
- Steam: ejects just hot steam

Traps triggers when an enemy touches the middle. After being activated it has a short cooldown.

Traps have a chance of receiving damage from every activation

When traps trigger they consume steam from their own buffer, which is refilled by the network.

### Power
Every steam node (boiler, relay boiler, pipe, trap) is a buffer with its own volume. Pressure is steam relative to volume, so a higher volume loses less pressure when steam is taken out.
- Boiler - volume 10, produces 10 steam per second
- Relay boiler - volume 5, produces nothing
- Pipes - volume 1
- Traps - have their own buffer, volume 2. Every activation takes steam from it; without enough steam the trap doesn't fire

Boilers, Relay Boilers and Pipes have a (small) chance on every tick to receive a damage point (max 5).

### Enemies
There are three classes of enemies:
- goblin scrapers
  - takes damage from everything
- goblin engineer
  - reduced damage from saws and steam
- goblin fighter
  - more hitpoints than scrapers

Behaviour:
- Enemies explore the tower with the goal of finding the heart.
- When enemies find loot, they return home.
- When enemies take near lethal damage (< 25% hitpoints) they have a chance of returning home.
- When the path to the core is known but is obstructed they destroy walls.

Enemies have a two part memory system:
- personal tower memory
- shared tower memory, this memory is applied to the personal memory when spawning

Enemies explore the tower, they don't directly know the route. Enemies that make it out report back parts of the tower and it's registered in the shared memory.

### Pressure system
Pipes connect automatically to every pipe that shares a corner of the tile grid, and machinery connects to the pipes on the edges of its tile. Machines on neighbouring tiles share steam directly, without pipes. The layout is worked out when something is placed or removed (`SteamLinks`); after that every node keeps its own neighbour list.

Steam is spread by each node itself, every frame:
1. Boilers produce steam, and nodes can leak steam in based on its damage points. Damage is not propagated.
2. Neighbouring nodes equalise pressure. The flow is volume weighted and the rate is capped by the number of connections, so the network is stable.

Distance loss, trap consumption and leaks therefore emerge from the pressure gradient. A damaged node drains, and its neighbours refill it from the rest of the network.

Damaged nodes can be repaired for scrap.

### Pathfinding

When an enemy enters the tower they will move forward on air tiles, exploring.
When close to another enemy they share their knowledge periodically.
When the tower core is known, pathfinding will switch to this.
When the tower core is known and unreachable due to walls, these walls become an intermediate target when known
When the tower core is unknown and not reachable known walls become a target.
When no tower core and blocking walls are known the goblins explore.

### Loot

Goblins like things that are loose, throughout the tower there are chests and other storage that they like to rummage through and bring home.

These loot places have a penalty if pipes run through and need to be repaired after.

### Win / Loss

Loss: when the tower core is destroyed
Win: timer, survive until the tower core activates

## Technical design

Notes:
- No game saving, just pausing/resume
- When opening the menu, the MenuState shows

```
App
-> World
-> GameState
   => MenuState (handles new or resume a paused game)
      -> UI Elements
   => PlayState (Plays and renders world)
      -> UI Elements
   => GameOverState (renders world)
      -> UI Elements
```

```
World 
-> Wave Spawner
-> Enemy SharedMemory
-> Enemy
   -> Pathfinder
   -> Memory
-> Tile
   -> TileContent
      => Solid
      => Air
         -> Edge 
            => None
            => Pipe
            => Wall
         -> Content
            => Loot
            => Tower core
            => Boiler
            => Relay Boiler
            => Trap
               => Crusher
               => Nails
               => Saw
               => Steam
```

### Edges
Edges share ownership between tiles.
When one tile removes its edge it's propegated to its neighbour.
